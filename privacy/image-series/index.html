Privacy Policy — Image SeriesПолітика приватності — Image Series

Last updated: 2026-09-20 · Applies specifically to the Image Series Chrome extension, published under the Terminal_Q brand. Востаннє оновлено: 2026-09-20 · Стосується конкретно розширення Image Series для Chrome, опублікованого під брендом Terminal_Q.

This page describes exactly what Image Series does, in addition to the general Terminal_Q privacy policy. Where the two differ in detail, this page is authoritative for Image Series. Ця сторінка описує саме те, що робить Image Series, доповнюючи загальну політику приватності Terminal_Q. Якщо в деталях вони розходяться, для Image Series чинна саме ця сторінка.

1. What Image Series is1. Що таке Image Series

Image Series is a Chrome extension that helps users submit a series of image-generation prompts to ChatGPT, through the user's own existing ChatGPT session, and download the resulting images. It has no account system and no API key of its own — it drives the ChatGPT tab the user already has open. Image Series — це розширення для Chrome, яке допомагає користувачу надсилати серію промптів для генерації зображень у ChatGPT через уже відкриту сесію ChatGPT користувача і завантажувати отримані зображення. У розширення немає власної системи акаунтів і власного API-ключа — воно керує вже відкритою вкладкою ChatGPT користувача.

2. Data the extension processes2. Які дані обробляє розширення

The extension processes only the information needed to provide its user-requested functionality:Розширення обробляє лише ту інформацію, яка потрібна для виконання функції, яку запросив користувач:

  • prompt text entered or imported by the user;текст промптів, введений чи імпортований користувачем;
  • reference images selected by the user for image editing;зразкові зображення, обрані користувачем для редагування;
  • content and generated-image elements visible in the user's open ChatGPT tab;вміст і згенеровані зображення, видимі у відкритій вкладці ChatGPT користувача;
  • temporary progress information, task status, and user-selected settings;тимчасова інформація про прогрес, статус завдань і налаштування, обрані користувачем;
  • generated image data needed to save requested PNG files.дані згенерованого зображення, потрібні для збереження запитаних PNG-файлів.

This information may qualify as "website content" under Chrome Web Store terminology. Ця інформація може підпадати під категорію "вміст вебсайту" за термінологією Chrome Web Store.

3. How data is used3. Як використовуються дані

Prompt text and any user-selected reference images are submitted to ChatGPT through the user's existing ChatGPT session only when the user starts a series. The extension reads the resulting response and generated image from that same tab so it can show progress and save the requested file. Текст промптів і будь-які обрані користувачем зразкові зображення надсилаються в ChatGPT через наявну сесію ChatGPT користувача лише тоді, коли користувач запускає серію. Розширення зчитує відповідь і згенероване зображення з тієї самої вкладки, щоб показати прогрес і зберегти запитаний файл.

Processing performed by the extension takes place locally in the browser. Image Series does not operate an external analytics, advertising, profiling, or data-collection server. Обробка, яку виконує розширення, відбувається локально в браузері. Image Series не має власного зовнішнього сервера аналітики, реклами, профілювання чи збору даних.

4. Storage and retention4. Зберігання та термін зберігання

The extension stores limited task progress and preferences in Chrome local extension storage so an interrupted series can be resumed. Reference images are saved in the browser's local storage (IndexedDB) on the user's device, so an interrupted series can be resumed without selecting them again; they are never sent to the developer. Generated images are downloaded to the location selected by Chrome. Local progress and saved reference images can be removed by starting a new series, clearing the extension's data, or uninstalling the extension. Розширення зберігає обмежену інформацію про прогрес завдань і налаштування в локальному сховищі розширення Chrome, щоб перервану серію можна було відновити. Зразкові зображення тримаються лише в пам'яті, поки відкрита бічна панель, і не зберігаються в сховищі розширення — після повторного відкриття користувачу потрібно обрати їх знову, щоб відновити серію, яка їх використовувала. Згенеровані зображення завантажуються туди, куди вказує Chrome. Локальний прогрес можна видалити, розпочавши нову серію, очистивши сховище розширення або видаливши розширення.

5. Sharing and sale of data5. Передача та продаж даних

Image Series does not sell personal information or user data. It does not transfer user data to advertising networks, data brokers, or unrelated third parties. Prompts, reference images, and the related ChatGPT page content are processed through ChatGPT at the user's own request and are therefore subject to OpenAI's own terms and privacy policy. Image Series не продає персональну інформацію чи дані користувачів. Розширення не передає дані користувачів рекламним мережам, брокерам даних чи стороннім особам, не пов'язаним із роботою розширення. Промпти, зразкові зображення та відповідний вміст сторінки ChatGPT обробляються через ChatGPT на власний запит користувача, тому на них поширюються умови й політика приватності самого OpenAI.

6. Permissions6. Дозволи

The extension requests access only to ChatGPT pages and the Chrome capabilities required to open its side panel, communicate with that tab, preserve progress, and download completed images. It does not read unrelated websites or browsing history. Розширення запитує доступ лише до сторінок ChatGPT і тих можливостей Chrome, які потрібні, щоб відкрити бічну панель, обмінюватися даними з цією вкладкою, зберігати прогрес і завантажувати готові зображення. Воно не читає інші сайти чи історію перегляду.

Image Series is currently free, with no license, subscription, or in-extension payment of any kind. This page will be updated before any paid tier is introduced. Наразі Image Series безкоштовне — без ліцензії, підписки чи будь-якого платежу всередині розширення. Цю сторінку буде оновлено ще до впровадження будь-якого платного рівня.
